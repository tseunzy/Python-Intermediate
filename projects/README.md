

**Simple Banking System**

    A command-line banking system built with Python that simulates basic banking operations. This project demonstrates core Python concepts including variables, data structures, functions, loops, and conditionals.


**📋 Features**

**Account Management**

    ✅ Create new accounts with auto-generated account numbers
    ✅ Close accounts (balance must be zero)
    ✅ View all accounts (admin access only)

**Banking Operations**

    ✅ Deposit money into accounts
    ✅ Withdraw money with PIN verification
    ✅ Transfer funds between accounts
    ✅ Check account balance
    ✅ Change account PIN

**Security Features**

    ✅ PIN authentication for sensitive operations
    ✅ Admin access control for account listing
    ✅ Transaction history tracking

**Transaction Tracking**

    ✅ Complete transaction history for each account
    ✅ Timestamps for all transactions
    ✅ View transaction logs
